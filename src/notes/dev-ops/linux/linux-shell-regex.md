# 第二十章：正则表达式入门

​		**正则表达式使用单个字符串来描述、匹配一系列符合某个语法规则的字符串。在很多文 本编辑器里，正则表达式通常被用来检索、替换那些符合某个模式的文本。在 Linux 中，grep， sed，awk 等文本处理工具都支持通过正则表达式进行模式匹配**

## 1. 常规匹配

一串不包含特殊字符的正则表达式匹配它自己，例如：

``` shell
cat /etc/passwd | grep atguigu
```

就会匹配所有包含 atguigu 的行

## 2. 常用特殊字符

* **特殊字符：**``^``

​		``^`` 匹配一行的开头，例如：

``` shell
cat /etc/passwd | grep ^a
```

![image-20220705223843225](../../../assets/posts/linux/image-20220705223843225.png)

> 会匹配出所有以 a 开头的行

* **特殊字符：** ``$``

​		``$`` 匹配一行的阶数，例如：

``` shell
cat /etc/passwd | grep t$
```

![image-20220705224011665](../../../assets/posts/linux/image-20220705224011665.png)

> 会匹配出所有以 t 结尾的行

* **特殊字符：** ``.``

​		``.`` 匹配一个任意的字符，例如：

``` shell
cat /etc/passwd | grep r..t
```

![image-20220705224235354](../../../assets/posts/linux/image-20220705224235354.png)

> 会匹配所有 r 和 t 之间包含两个字符的行

* **特殊字符：** ``*``

​		``*`` 不单独使用，他和上一个字符连用，表示匹配上一个字符 0 次 或 多次，例如：

``` shell
cat /etc/passwd | grep ro*t
```

![image-20220705224513533](../../../assets/posts/linux/image-20220705224513533.png)

> 会匹配所有 r 和 t 之间包含 0个 或多个 o 的行

``.*`` **会匹配一个任意的字符串**

* **字符区间（中括号）：** ``[]``

``[]`` 表示匹配某个范围内的一个字符，例如：

| 正则           | 含义                               |
| -------------- | ---------------------------------- |
| **[6,8]**      | **匹配 6 或者 8**                  |
| **[0-9]**      | **匹配一个 0-9 的数字**            |
| **[0-9]***     | **匹配任意长度的数字字符串**       |
| **[a-z]**      | **匹配一个 a-z 之间的字符**        |
| **[a-z]***     | **匹配任意长度的字母字符串**       |
| **[a-c, e-f]** | **匹配 a-c 或者 e-f 之间的任意字** |

``` shell
cat /etc/passwd | grep r[a,b,c]*t
```

![image-20220705230704767](../../../assets/posts/linux/image-20220705230704767.png)

> 会匹配所有的 r 后面跟着任意多个 a 或 b 或 c 的行

* **特殊字符：** ``\``

``\`` 表示转义，并不会单独使用。由于所有特殊字符都有其特定匹配模式，当我们想匹配 某一特殊字符本身时（例如，我想找出所有包含 '$' 的行），就会碰到困难。此时我们就要 将转义字符和特殊字符连用，来表示特殊字符本身，例如：

``` shell
cat /etc/passwd | grep 'a\$b'
```

> 就会匹配所有包含 a$b 的行。注意需要使用单引号将表达式引起来
